== Requirements

* link:https://www.php.net[PHP]
* link:https://getcomposer.org/[Composer]
* Commandline / Shell (opt.)
** Linux / Unix Shell or
** Windows Shell

== Configuration

=== Unix / Linux

* Clone this repository to your local drive
* run `./bin/install.sh`
* Edit the file `${HOME}/.yacorapi/MyAuth.php`
** Replace `\#confluence-url_for_production#` with your Confluence URL for the production environment
** Replace `\#confluence-url_for_testing#` with your Confluence URL for the testing environment
* Edit the file `${HOME}/.yacorapi/MySpaces.php`
** Replace `\#spacekey-single#` with your primary spacekey
** Replace `\#spacekey-simple1#`,`\#spacekey-simple2#` with your primary and secondary spacekey
** Replace `\#spacekey-all1#` ... `\#spacekey-alln#` with all spacekeys on the instance

=== Windows

* Clone this repository to your local drive
* run `bash .\bin\install.sh`
* Edit the file `%USERPROFILE%\.yacorapi\MyAuth.php`
** Replace `\#confluence-url_for_production#` with your Confluence URL for the production environment
** Replace `\#confluence-url_for_testing#` with your Confluence URL for the testing environment
* Edit the file `%USERPROFILE%\.yacorapi\MySpaces.php`
** Replace `\#spacekey-single#` with your primary spacekey
** Replace `\#spacekey-simple1#`,`\#spacekey-simple2#` with your primary and secondary spacekey
** Replace `\#spacekey-all1#` ... `\#spacekey-alln#` with all spacekeys on the instance
